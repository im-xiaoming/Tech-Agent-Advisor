TECH_CHATBOT_RAG_MULTIAGENT_APP - NỘI DUNG DỰ ÁN
=================================================

1. Tổng Quan
------------

Đây là một ứng dụng chatbot tư vấn sản phẩm công nghệ được xây dựng bằng Django.
Ứng dụng kết hợp RAG, Qdrant vector database, LangChain/LangGraph, LLM và giao diện
chat streaming để trả lời câu hỏi về sản phẩm dựa trên dữ liệu nội bộ.

Mục tiêu chính của dự án:
- Cho phép người dùng đăng ký, đăng nhập và trò chuyện với chatbot.
- Tư vấn sản phẩm công nghệ dựa trên kho dữ liệu RAG.
- Truy hồi tài liệu sản phẩm từ Qdrant, rerank kết quả, rồi sinh câu trả lời có trích dẫn.
- Lưu lịch sử chat theo từng tài khoản người dùng.
- Lưu log hội thoại, điểm groundedness và trạng thái nghi ngờ hallucination để staff review.
- Cho phép staff chỉnh sửa file cấu hình `.config/config.yaml` qua giao diện quản trị.

Stack chính:
- Backend web: Django 5.2.
- Database ứng dụng: SQLite mặc định qua `db.sqlite3`.
- Vector database: Qdrant Cloud thông qua `langchain-qdrant`.
- LLM: Ollama local hoặc Google Gemini.
- Embedding: HuggingFaceEmbeddings hoặc OllamaEmbeddings.
- Điều phối RAG: LangGraph và các agent riêng.
- Reranking/groundedness: HuggingFace cross-encoder.
- Frontend chat: HTML/CSS/JavaScript, nhận token stream theo kiểu Server-Sent Events.


2. Cấu Trúc Thư Mục Cấp Cao
---------------------------

`manage.py`
- Entry point của Django command line.
- Dùng để chạy server, migrate database, tạo superuser và build RAG index.

`requirements.txt`
- Danh sách dependency Python.
- Các dependency quan trọng gồm Django, LangChain, LangGraph, Qdrant client,
  transformers, sentence-transformers, torch, BeautifulSoup, requests, PyYAML,
  python-dotenv, langchain-ollama và langchain-google-genai.

`.config/config.yaml`
- File cấu hình runtime cho RAG.
- Chứa thông số chunking, retriever, hybrid search, reranker, chat history,
  splitter, embedding và loader.
- File này được đọc khi import `rag_engine.core.config`, nên sau khi sửa cấu hình
  thường cần restart Django server để toàn bộ runtime nhận giá trị mới.

`data/cellphones_mobile.jsonl`
- Dữ liệu sản phẩm dạng JSON Lines.
- Mỗi dòng là một sản phẩm được crawl từ CellphoneS.
- Các field chính: `url`, `title`, `description`, `specs`, `specs_kv`,
  `images`, `price_raw`, `price`, `brand`, `rating`, `reviews_count`, `text`.

`crawler/`
- Script thu thập dữ liệu sản phẩm từ CellphoneS.

`rag_engine/`
- Phần lõi RAG và multi-agent.
- Gồm cấu hình, LLM, embedding, ingestion, loader, chunking, vector store,
  retriever, reranker, filter, citation, groundedness và các agent.

`chat/`
- Django app cho giao diện chat, API chat streaming và đồng bộ lịch sử hội thoại.

`accounts/`
- Django app cho đăng nhập, đăng ký, đăng xuất và model lưu conversation.

`manager/`
- Django app cho staff quản lý config và review chat log.

`landing/`
- Trang landing đầu vào của website.

`templates/`, `static/`
- Template và static asset dùng chung.

6. App `chat`
-------------

Vai trò:
- Render UI chat.
- Nhận request chat từ frontend.
- Stream token về frontend.
- Đồng bộ lịch sử chat với database.

Routes trong `chat/urls.py`:
- `/` -> `chat_view`, tên route `home`.
- `/chat/` -> `chat_view`, tên route `chat-view`.
- `/message/` -> `chat_message`, API POST streaming.
- `/history/` -> `chat_history`, GET/POST lịch sử chat.
- `/history/clear/` -> `chat_history_clear`.
- `/history/<chat_id>/` -> `chat_history_detail`.

`chat/views.py`
- `_build_history_context(histories)`
  - Nhận history từ frontend.
  - Nếu history là list, tách thành message.
  - Lấy config `num_chats_retained`.
  - Các message cũ có thể được summarize bằng `summarize_history`.
  - Các message gần đây được giữ raw để LLM hiểu ngữ cảnh.

- `chat_message(request)`
  - Yêu cầu login và POST.
  - Parse JSON body.
  - Lấy `query`, `history`, `session_id`.
  - Gọi `stream_chat(...)`.
  - Trả về `StreamingHttpResponse` với content type `text/event-stream`.
  - Set `Cache-Control: no-cache` và `X-Accel-Buffering: no`.

- `chat_history(request)`
  - GET: trả về conversation của user hiện tại.
  - POST: nhận list chat từ frontend và `update_or_create` vào `ChatConversation`.

- `chat_history_detail(request, chat_id)`
  - DELETE một conversation của user.

- `chat_history_clear(request)`
  - Xóa tất cả conversation của user.

- `chat_view(request)`
  - Render `chat/chat.html`.
  - Truyền các URL API vào template.

`chat/services.py`
- Service format event stream cho frontend.
- `_sse(event)` biến dict thành format `data: {...}\n\n`.
- `stream_chat(query, history, user, session_id)`
  - Gọi `rag_engine.rag.pipeline.ask_stream`.
  - Stream các event:
    - `sources`: danh sách source sau retrieval.
    - `token`: token/chunk sinh ra từ LLM.
    - `regenerating`: yêu cầu UI xóa câu trả lời đang stream và bắt đầu lại.
    - `low_confidence`: đánh dấu câu trả lời có độ tin cậy thấp.
    - `error`: lỗi nếu pipeline fail.
    - `done`: kết thúc stream.
  - Sau khi stream xong, tạo background thread để lưu `ChatLog`.

- `_persist_log(...)`
  - Lưu query, answer, context, retrieved docs, sources, latency, top_k, model.
  - Nếu reranker bật và có context, tính groundedness bằng `score_answer`.
  - Gán flag `ok`, `suspicious` hoặc `unchecked`.

Frontend:
- `chat/templates/chat/chat.html`
  - Layout chat có sidebar, history, welcome screen, message area, input, settings modal.
  - Gắn `data-chat-api-url`, `data-chat-history-url`, `data-chat-history-clear-url`.

- `static/js/script.js`
  - Quản lý local state: `chats`, `currentChatId`, settings UI.
  - Load/save chat history từ server, fallback localStorage nếu server lỗi.
  - Gửi POST đến chat API bằng `fetch`.
  - Đọc `response.body.getReader()` và parse các SSE chunk.
  - Render token streaming trực tiếp vào message bot.
  - Xử lý `sources`, `regenerating`, `low_confidence`, `done`, `error`.
  - Format Markdown cơ bản, table, list, heading, inline code.

8. RAG Engine - Cấu Hình Và Core
--------------------------------

`rag_engine/core/config.py`
- Đọc `.config/config.yaml`.
- Tạo dataclass immutable `Settings`.
- Gồm các nhóm cấu hình:
  - Đường dẫn: `base_dir`, `data_dir`, `storage_dir`, `prompt_path`.
  - Loader: `loader_type`.
  - Embedding: provider, model, dimension.
  - Splitter/chunking: method, chunk_size, chunk_overlap.
  - LLM: provider, model, Gemini API key.
  - Qdrant: URL, API key, collection.
  - Retriever: score threshold, hybrid, sparse model, self-query filter.
  - Reranker: enabled, model, top_n, candidate multiplier, thresholds.
  - Chat history: retained turns, max length, beam size.

Environment variables quan trọng:
- `LLM_PROVIDER`: `ollama` hoặc `gemini`.
- `LLM_MODEL`: tên model LLM.
- `GEMINI_API_KEY` hoặc `GOOGLE_API_KEY`.
- `QDRANT_URL`.
- `QDRANT_API_KEY`.
- `QDRANT_COLLECTION`.
- `RAG_TOP_K`.
- `RAG_TEMPERATURE`.

`rag_engine/core/llm.py`
- Kết nối LLM.
- `_get_llm_model(...)`
  - Nếu provider là Gemini và có `GOOGLE_API_KEY`, tạo `ChatGoogleGenerativeAI`.
  - Nếu không, dùng `ChatOllama`.
  - Cache theo temperature/reasoning.

- `generate_response(...)`
  - Gọi LLM non-stream.

- `generate_response_stream(...)`
  - Stream chunk từ LLM.

- `_strip_reasoning(...)`
  - Xóa block `<think>...</think>` nếu model reasoning sinh ra.

- `classify_and_rewrite(query, history)`
  - Một lần gọi LLM để:
    - classify intent: `smalltalk`, `product_advice`, `invalid`.
    - rewrite query cho retrieval.
    - extract filters: `brand`, `price_min`, `price_max`, `ram_min`,
      `storage_min`, `battery_min`.
  - Nếu parse JSON fail, fallback thành `product_advice` với query gốc.

- `_sanitize_filters(raw)`
  - Chỉ giữ key hợp lệ.
  - Ép numeric filters thành float.

- `rewrite_query_for_retrieval(...)`
  - Hàm rewrite riêng, hiện tại vẫn tồn tại nhưng luồng chính đang dùng
    `classify_and_rewrite`.

- `classify_intent(...)`
  - Hàm classify riêng, hiện tại là helper cũ/dự phòng.

- `summarize_history(...)`
  - Tóm tắt lịch sử cũ để giảm context dài.

`rag_engine/core/embedding.py`
- `get_embeddings()` trả về embedding object đã cache.
- Nếu `embedding_provider == 'ollama'`, dùng `OllamaEmbeddings`.
- Nếu không, dùng `HuggingFaceEmbeddings`.
- HuggingFace chọn `cuda` nếu có GPU, ngược lại dùng CPU.

`rag_engine/core/prompt_loader.py`
- Load prompt từ `prompts/`.
- Cache prompt file bằng `lru_cache`.
- `load_advisor_prompt()` load advisor system/user prompt.
- `load_smalltalk_prompt()` load smalltalk system/user prompt.


9. Prompt Files
---------------

`prompts/advisor/system_prompt.txt`
- System prompt cho agent tư vấn sản phẩm.
- Yêu cầu trả lời bằng tiếng Việt.
- Chỉ được dùng CONTEXT, không bịa thông tin.
- Mỗi câu có thông tin sản phẩm phải có citation `[N]`.
- Không so sánh/xếp hạng nếu context không đủ tiêu chí.
- Không nhắc đến system prompt hoặc rules.

`prompts/advisor/user_prompt.txt`
- Đưa lịch sử hội thoại, CONTEXT và QUESTION vào prompt.
- Nhắc lại rằng CONTEXT là nguồn duy nhất.
- Bắt buộc gắn citation `[N]`.
- Nếu context trống/không liên quan, trả lời fallback tiếng Việt.
- Có placeholder `{extra_instructions}` cho lần regenerate.

`prompts/smalltalk/system_prompt.txt`
- System prompt cho greeting/cảm ơn/tạm biệt/xã giao.
- Luôn trả lời bằng tiếng Việt.
- Không đưa thông tin sản phẩm vì không có context sản phẩm.

`prompts/smalltalk/user_prompt.txt`
- Đưa history và query mới nhất vào smalltalk agent.
- Yêu cầu trả lời ngắn gọn.


10. RAG Ingestion Và Vector Store
---------------------------------

`rag_engine/ingestion/build_index.py`
- `build_index(data_dir=None)`
  - Load dữ liệu từ `settings.data_dir`.
  - Split document thành chunks.
  - Tạo/rebuild vector DB trong Qdrant.

`chat/management/commands/build_rag_index.py`
- Django management command:
  - `python manage.py build_rag_index`
  - Option: `--data-dir`.
  - Sau khi build xong in số vector trong collection.

`rag_engine/rag/loader.py`
- `load_data(directory_path=None)`
  - Nếu `loader.type == jsonl`, dùng `DirectoryLoader` và `JSONLoader`.
  - Nếu không, load CSV bằng `CSVLoader`.

`rag_engine/rag/tools/jsonl.py`
- Custom `JSONLoader` cho CellphoneS JSONL.
- Mỗi record JSONL được biến thành `langchain_core.documents.Document`.
- `page_content` gồm:
  - Product, Brand, Price, Source URL.
  - Description.
  - Rating/review count.
  - Structured features.
  - Specification key-value.

- Metadata gồm:
  - `source`, `file_source`, `line_number`.
  - `title`, `brand`, `price`, `scraped_at`.
  - `chipset`, `ram_gb`, `storage_gb`, `battery_mah`.
  - camera features: rear/front MP, aperture, OIS, telephoto, ultrawide,
    camera_score.
  - `performance_score`.

- Có xử lý normalize text bị lỗi encoding, extract số GB/mAh/MP và các feature camera.
- Numeric missing được để `None` để Qdrant payload index không gặp mixed-type value.

`rag_engine/rag/chunking.py`
- Chọn splitter theo config:
  - `tiktoken`: `RecursiveCharacterTextSplitter.from_tiktoken_encoder`.
  - `sentence_transformer`: `SentenceTransformersTokenTextSplitter`.
  - mặc định: `RecursiveCharacterTextSplitter`.
- `split_docs(docs)` trả về list chunked Document.

`rag_engine/rag/vector_store.py`
- Wrapper nhỏ quanh Qdrant implementation:
  - `create_vector_db(chunks)`.
  - `load_vector_db()`.
  - `count_vectors(db)`.

`rag_engine/rag/vector_store_qdrant.py`
- Kết nối Qdrant Cloud bằng `QdrantClient`.
- Dùng `QdrantVectorStore` của LangChain.
- Hỗ trợ 2 chế độ:
  - Dense only.
  - Hybrid dense + sparse BM25 nếu `hybrid_enabled = true`.

- Vector names:
  - Dense: `dense`.
  - Sparse: `sparse`.

- Payload indexes được tạo để filter metadata hoạt động:
  - `metadata.price` float.
  - `metadata.ram_gb` float.
  - `metadata.storage_gb` float.
  - `metadata.battery_mah` float.
  - `metadata.brand` text.

- `create_qdrant_db(chunks, collection_name=None)`
  - Xóa collection cũ nếu có.
  - Tạo collection mới đúng dimension của embedding hiện tại.
  - Tạo payload indexes.
  - Add documents theo batch 32.

- `load_qdrant_db(collection_name=None)`
  - Kiểm tra collection tồn tại.
  - Đảm bảo payload indexes.
  - Trả về vector store đã sẵn sàng query.

- `_embedding_dim()`
  - Embed câu "dim probe" để lấy dimension thực tế.


11. Retriever, Filters, Reranker Và Guardrails
----------------------------------------------

`rag_engine/rag/retriever.py`
- `retrieve(db, query, k, score_threshold, filters)`
  - Convert filter dict thành Qdrant Filter bằng `build_qdrant_filter`.
  - Gọi `db.similarity_search(query, **kwargs)`.
  - Có `score_threshold` nếu config > 0 hoặc pass explicit.
  - Nếu Qdrant từ chối filter, retry không filter để chat vẫn hoạt động.

`rag_engine/rag/tools/filters.py`
- Convert structured filters sang Qdrant filter.
- Supported filters:
  - `brand` -> match text trên `metadata.brand`.
  - `price_min` -> `metadata.price >= value`.
  - `price_max` -> `metadata.price <= value`.
  - `ram_min` -> `metadata.ram_gb >= value`.
  - `storage_min` -> `metadata.storage_gb >= value`.
  - `battery_min` -> `metadata.battery_mah >= value`.

`rag_engine/rag/tools/reranker.py`
- Rerank documents bằng cross-encoder HuggingFace.
- Model mặc định từ config: `Alibaba-NLP/gte-multilingual-reranker-base`.
- Lazy load tokenizer/model.
- Nếu có CUDA thì model chạy GPU.
- Score query-document pairs, sigmoid về range 0..1.
- Gắn `metadata["rerank_score"]` vào document.

`rag_engine/rag/tools/groundedness.py`
- Tính groundedness bằng cách score answer với từng context chunk.
- Lấy max cross-encoder score làm tín hiệu.
- Dùng để flag suspicious và quyết định regenerate.

`rag_engine/rag/tools/citation.py`
- Parse citation dạng `[N]`.
- `verify_citations(answer, num_docs)` kiểm tra:
  - Có citation không.
  - Citation có vượt range retrieved docs không.
  - Câu trả lời dài hơn ngưỡng nhưng không có citation thì xem là missing.

`rag_engine/agents/guardrails/agent.py`
- `no_context_guardrail_agent(state)`
  - Trả lời fallback khi retrieval không lấy được document liên quan.
  - Gắn error `"No retrieved context."`.


12. Multi-Agent Workflow
------------------------

State schema:
- `rag_engine/agents/state.py`
- `AgentState` là TypedDict truyền giữa các node.
- Field chính:
  - `query`
  - `original_query`
  - `history`
  - `filters`
  - `route`
  - `retrieved_docs`
  - `context`
  - `answer`
  - `error`
  - `sources`
  - `top_k`
  - `temperature`

Graph:
- `rag_engine/agents/graph.py`
- `build_chat_graph(db, top_k=None)` tạo LangGraph:
  - Entry point: `supervisor`.
  - Nếu route `product_advice` -> `retrieval`.
  - Nếu route `smalltalk` -> `smalltalk`.
  - Nếu invalid -> END.
  - Sau retrieval:
    - Có docs -> `advisor`.
    - Không có docs -> `no_context_guardrails`.
  - `advisor`, `smalltalk`, `no_context_guardrails` đều kết thúc graph.

Supervisor:
- `rag_engine/agents/supervisor/agent.py`
- `supervisor_agent(state)`
  - Query rỗng -> invalid + answer yêu cầu nhập câu hỏi.
  - Gọi `classify_and_rewrite(query, history)`.
  - Nếu `settings.self_query_enabled`, lấy filters từ LLM decision.
  - `smalltalk`: giữ query gốc, route smalltalk.
  - `product_advice`: đổi query thành rewritten query, lưu original_query và filters.

Retrieval agent:
- `rag_engine/agents/retrieval/agent.py`
- `make_retrieval_agent(db, default_top_k)`
  - Lấy `top_k`, `query`, `filters`.
  - Nếu reranker bật:
    - Fetch nhiều hơn top_k theo `candidate_multiplier`.
    - Rerank candidate.
    - Cắt về top_k.
    - Có thể lọc theo `min_rerank_score`.
  - Nếu không bật reranker: retrieve trực tiếp top_k.
  - Fallback A: nếu filter làm mất hết kết quả, retry không filter.
  - Fallback B: nếu rewritten query không có kết quả, retry bằng original query.
  - Đánh số docs `[1]`, `[2]`, ... vào context để advisor cite.
  - Tạo `sources` từ metadata source.

Advisor agent:
- `rag_engine/agents/advisor/agent.py`
- `_build_advisor_prompts(state, extra_instructions)`
  - Load prompt advisor.
  - Inject context, query, history, extra instructions.
- `advisor_agent(state)`
  - Gọi LLM non-stream để sinh answer.
- `stream_advisor_tokens(state, extra_instructions)`
  - Stream token từ LLM.
- `smalltalk_agent(state)` và `stream_smalltalk_tokens(state)`
  - Tương tự advisor nhưng dùng prompt smalltalk.


13. Chat Pipeline Runtime
-------------------------

`rag_engine/rag/pipeline.py`
- API cấp cao cho Django gọi.

`get_default_db()`
- Load Qdrant vector DB và cache.

`get_default_graph()`
- Build LangGraph và cache.

`ask(query, history, db=None, temperature=None, top_k=None)`
- Non-stream pipeline.
- Gọi graph compiled.
- Trả về answer, sources, error, retrieved_docs, context, route.

`ask_stream(query, history, db=None, temperature=None, top_k=None)`
- Generator streaming được `chat.services.stream_chat` sử dụng.
- Luồng xử lý:
  1. Tạo initial state với query, history, temperature, top_k.
  2. Gọi `supervisor_agent`.
  3. Nếu invalid: yield sources rỗng, token answer fallback, final.
  4. Nếu smalltalk: stream smalltalk tokens, final.
  5. Nếu product_advice:
     - Gọi retrieval agent.
     - Nếu không có docs: guardrail fallback.
     - Nếu có docs: yield sources, stream advisor tokens.
  6. Sau khi sinh xong:
     - Verify citations.
     - Tính groundedness nếu reranker bật.
     - Nếu citation/groundedness fail và regenerate bật:
       - Yield `regenerating`.
       - Sinh lại với `_REGEN_INSTRUCTIONS`.
       - Re-evaluate.
  7. Nếu low confidence, yield `low_confidence`.
  8. Yield final state.

`_REGEN_INSTRUCTIONS`
- Instruction thêm cho lần viết lại nếu câu trả lời thiếu căn cứ/citation.

`_evaluate_answer(answer, context, num_docs)`
- Chạy `verify_citations`.
- Chạy `score_answer` nếu bật reranker.
- Quyết định `needs_regen` và lý do.

18. Các Điểm Cần Chú Ý Khi Phát Triển
--------------------------------------

Qdrant payload index:
- Khi bật self-query filter, Qdrant cần payload index cho field filter.
- Project đã có `_ensure_payload_indexes` trong `vector_store_qdrant.py`.
- Nếu collection cũ có metadata mixed-type, index có thể fail và retriever sẽ fallback
  retry không filter.

Embedding dimension:
- Dimension trong config phải khớp model embedding.
- `BAAI/bge-m3` thường dùng dimension 1024.
- Nếu đổi embedding model, nên rebuild collection.

Hybrid search:
- `hybrid_enabled: true` cần collection có dense vector và sparse vector.
- Nếu đổi dense-only sang hybrid, cần rebuild collection.

Config runtime:
- `Settings` được tạo lúc import.
- Sau khi sửa `.config/config.yaml`, nên restart server.

Prompt/cache:
- Prompt được cache bằng `lru_cache`.
- Nếu sửa prompt file khi server đang chạy, có thể cần restart để đảm bảo prompt mới được load.

Streaming:
- Backend stream event theo format SSE.
- Frontend đọc raw stream bằng `fetch` + `ReadableStream`.
- Event `regenerating` báo frontend reset answer đang hiển thị.

Groundedness:
- Groundedness dùng cùng reranker cross-encoder.
- Nếu reranker/model nặng, lần đầu có thể chậm vì phải load model.

Security/dev:
- `DEBUG=True` và hard-coded `SECRET_KEY` phù hợp dev, không phù hợp production.
- Production cần chuyển secret/env, config `ALLOWED_HOSTS`, static files và database riêng.
